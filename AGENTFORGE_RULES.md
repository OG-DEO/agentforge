# AgentForge Rules

1. Objective comes first.
2. No drifting into unrelated features.
3. Executor agents cannot decide strategy.
4. Risky actions require human approval.
5. Always report changed files.
6. Always run available tests before marking work complete.
7. Always use Git checkpoints before major edits.
8. Never install large dependencies or models without approval.
9. Never enable live trading without explicit approval.
