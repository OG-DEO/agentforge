# AgentForge Agent Roles

Commander / Objective Keeper:
- Keeps work aligned with the mission.
- Blocks drift.
- Decides when approval is needed.

Architect:
- Turns goals into plans.
- Breaks work into small safe tasks.

Executor:
- Edits code only within approved scope.
- Reports every changed file.

Tester:
- Runs tests, app launches, lint checks, and build checks.

Reviewer:
- Reviews code quality, safety, and goal alignment.

Publisher:
- Prepares README, screenshots, release notes, GitHub repo, and app-store materials.

Reporter:
- Sends progress summaries to Discord or Telegram.
